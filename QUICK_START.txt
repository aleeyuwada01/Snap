🚀 DEPLOY TO NETLIFY (3 STEPS):
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

STEP 1: Setup Supabase
  → Go to: https://supabase.com/dashboard
  → Copy your Project URL (Settings → API)
  → Copy your Anon Key (Settings → API)
  → Run supabase_migration.sql in SQL Editor

STEP 2: Deploy to Netlify
  → Go to: https://app.netlify.com/
  → Click: Add new site → Import from Git
  → Select: GitHub → aleeyuwada01/Snap
  → Set Environment Variables:
     VITE_SUPABASE_URL = your_project_url
     VITE_SUPABASE_ANON_KEY = your_anon_key
  → Click: Deploy site

STEP 3: Test Your Site
  → Visit: your-site.netlify.app
  → Test login flow
  → Check: your-site.netlify.app/?dashboard=true
